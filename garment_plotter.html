Plotter

Garment Master Pen Plotter

Plotter is a hardware machine it’s like a printer which is used to draw line graphics or vector graphics designs. which is given inside the CAD system software for the plotter to design the specific design.

Line is which joins one line with another is said line graphics and vector graphics is which takes the 2D or 3D design and combines them into a high resolution design.

Description


The Garment master pen plotter. Adopt front paper load system. Invisible infrared control system. Derived by high speed stepper motor driver. Match with double spurts ink/HP ordinary HP45 type Ink cartridge.
