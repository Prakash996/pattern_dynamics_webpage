Fabric Auto Cutting Machine

ICut Top Line Cutter

Accelerate sewn-goods manufacturing with an eco-friendly and agile automatic fabric cutting machine. Precisely cut an extensive variety of materials, including knits, woven, and industrial fabrics.

Description


The Invencut is an integrated software to run the automatic cutter. Developed in windows environment, It allows to manage all cut data. A user-friendly graphic interface and easy-to-use concept make possible also non-skilled operators to run the icut auto cutter. It has optimization of cut files, pattern start point, cut sequence, common lines management, zero buffer cutting, dynamic speed control and best knife direction on nearby lines. It show on sceen display of every cut file information and details, including text for size detection.
