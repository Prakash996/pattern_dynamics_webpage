# Pattern Dynamics Webpage

A modern, responsive website showcasing Pattern Dynamics' automation products and services for the garment manufacturing industry.

## Overview

Pattern Dynamics is a leading provider of automation products and services for garment manufacturers, apparel designers, and brand houses internationally. This website presents their comprehensive portfolio of solutions and services.

## Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Product Showcase**: Detailed presentation of automation solutions including:
  - CAD/CAM Pattern & Grading Systems
  - Fabric Spreading Machines (Standard & CNC)
  - Inkjet Plotters (Vertical, Serials, Garment Master)
  - Fabric Cutting Machines (KP-X, KP-Y, iCut, Leather Cutter)
  - Labeling Solutions
  - Screen Printing Machines
  - Cutting Tables
- **Services Section**: Complete range of services including pattern making, grading, marker planning, and tech-pack creation
- **Team & Clients Display**: Information about the team and testimonials from clients
- **Contact Information**: Multiple ways to get in touch

## Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   ```

2. **Navigate to the project directory**
   ```bash
   cd pattern_dynamics_webpage
   ```

3. **Open in a web server**
   - Option 1: Open `index.html` directly in a browser (for basic viewing)
   - Option 2: Use a local web server for full functionality
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Python 2
     python -m SimpleHTTPServer 8000
     
     # Using Node.js (http-server)
     npx http-server
     ```

4. **Access the website**
   - Navigate to `http://localhost:8000` (or your chosen port)
